How to read this

Impressions
How many times a page appeared anywhere in Google results — reach, not visits.
Clicks
People who actually clicked through to the page from Google.
CTR (click-through rate)
Clicks ÷ impressions. Spine provider pages run ~3–5%; condition/treatment pages currently ~0.2–0.3%, which is the main fixable gap (title & description rewrites).
Δ impr.
Change in impressions, last 4 weeks (Jul 13 – Aug 9) vs the prior 4 (Jun 15 – Jul 12).
Dead URLs (404)
22 spine URLs return “page not found”. None had search activity in this 26-week window, so they don’t appear in the tables (a ✕ 404 marker appears on any that do). Every one has a proposed redirect in the consolidation map.
“301 planned”
This page is a duplicate or dead URL scheduled to consolidate into the canonical page shown, per the draft redirect map (pending SEO/dev review).

Method & caveats

Source: Google Search Console page-level data (aggregation: by page), spine pages identified by a validated URL pattern (topic keywords + the spine provider roster). Google search only — Bing not included. GSC data is finalized through Aug 9; weeks run Monday–Sunday. “404 / last seen” reflects Google’s index and GA4 titles, not a live crawl. Pages with zero impressions all window are listed inside each section. Full inventory & redirect map: data/ folder in the SHP marketing workspace repo.
